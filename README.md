# KnowMeMore — Portfolio of Aditi Kumari Singh

A personal portfolio website built with **React + Vite** — designed to showcase my projects, skills, experience, and the things I enjoy building and learning along the way.

🌐 **Live Website:**  
https://knowmemore-beta.vercel.app/

---

## 📌 About

This portfolio was built to create a space that feels personal, clean, and reflective of my interests in:

- Web Development  
- Data Analytics  
- UI/UX and Modern Interfaces  
- Continuous Learning in Tech  

I wanted it to feel less like a generic template and more like something that evolves over time — improved, redesigned, and refined with experience.

---

## ⚙️ Tech Stack

- React  
- Vite  
- Tailwind CSS  
- Framer Motion  
- React Router  

---

## ✨ Features

- 🌙 Dark / Light Mode toggle  
- 📱 Fully Responsive Design (Mobile, Tablet, Desktop)  
- 🎬 Smooth Animations and UI transitions  
- 📄 Resume Viewer with Download option  
- 🧭 Route-based Navigation  
- 🎓 Certifications Section with expandable modules  
- 💾 Theme persistence using localStorage  
- 🚀 Project showcase with live demo + GitHub links  

---

## 📂 Pages Overview

| Route | Description |
|------|-------------|
| `/` | Hero landing page |
| `/about` | About me, education, skills, experience, certifications |
| `/projects` | Project showcase with GitHub and live demo links |
| `/contact` | Contact form, social links, and resume access |
